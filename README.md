# Air-Quality-prediction-Machine-Learning-
Air Quality Prediction using Python and Machine Learning. This project implements and compares five regression models to predict RSPM/PM10 levels using the CPCB Tamil Nadu 2015 air quality dataset. Models are evaluated using MAE, MSE, RMSE, and R² Score.
# 🌍 Air Quality Prediction Using Machine Learning

## 📌 Project Overview
This project predicts air pollution levels (RSPM/PM10) using Machine Learning regression algorithms. It uses the CPCB Tamil Nadu 2015 dataset to analyze air quality and compare the performance of five regression models.

## 🎯 Objective
To predict PM10 concentration using SO2, NO2, and Month as input features and evaluate different regression algorithms.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## 🤖 Machine Learning Models
1. Simple Linear Regression
2. Multiple Linear Regression
3. Polynomial Regression
4. Decision Tree Regression
5. Support Vector Regression (SVR)

## 📊 Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## 📈 Project Visualizations
- RMSE Comparison of Regression Models
- Actual vs Predicted Values

## 📂 Project Files
- `air_quality_prediction.py` – Main Python source code.
- `cpcb_dly_aq_tamil_nadu-2015.csv` – Dataset.
- `model_comparison_results.csv` – Generated model comparison results.

## ⚙️ How to Run

Install the required libraries:

```bash
pip install pandas numpy matplotlib scikit-learn
```

Run the project:

```bash
python air_quality_prediction.py
```

Make sure the CSV dataset is in the same folder as the Python file.
